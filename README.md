# NHANES Finasteride AGA Proxy

Reproducibility code and classification dictionary accompanying the manuscript **“Development and Internal Evaluation of a Finasteride-Based Proxy for Probable Androgenetic Alopecia in NHANES.”**

## Contents

- `classification_dictionary.csv`: cycle-specific questionnaire rules, medication reason-for-use classifications, age criterion, and concurrent-medication definitions.
- `scripts/01_download_nhanes.py`: downloads the required public NHANES XPT files for 1999–2018.
- `scripts/02_build_proxy_cohort.py`: constructs the cycle-specific finasteride proxy and analytic survey-domain file.
- `scripts/03_validation_analyses.py`: reproduces age-cutoff and concurrent-medication validation summaries.
- `scripts/04_survey_weighted_analyses.R`: reproduces the final survey-weighted primary and sensitivity estimates using logit-transformed confidence intervals for proportions.
- `outputs/aggregate/`: aggregate, non–participant-level results generated by the verified analysis.

Raw NHANES files and participant-level derived files are intentionally excluded from the repository. The download script retrieves source files directly from the National Center for Health Statistics.

## Software

- Python 3.12 or later
- Python packages listed in `requirements.txt`
- R 4.6.1
- R package `survey` 4.5

## Reproduction

From the repository root:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/01_download_nhanes.py
python scripts/02_build_proxy_cohort.py
python scripts/03_validation_analyses.py
Rscript scripts/04_survey_weighted_analyses.R
```

For an existing local NHANES download, set `NHANES_RAW_DIR` before running scripts 02 and 03.

The scripts write participant-level intermediate files to `outputs/derived/`, which is excluded by `.gitignore`, and aggregate results to `outputs/aggregate/`.

## Primary proxy definition

- **1999–2008:** retain questionnaire-negative users and users below the applicable prostate-condition questionnaire eligibility age; exclude questionnaire-positive users and age-eligible users without usable questionnaire data.
- **2009–2012:** retain finasteride users aged younger than 40 years because neither prostate-condition questionnaire nor participant-reported medication reason-for-use data were available.
- **2013–2018:** retain explicit hair-loss indications; exclude explicit prostate indications; apply the prespecified age criterion to indeterminate indications. The primary manuscript definition additionally retains the single participant aged 22 years with code L98.9 as composite proxy evidence.
- Restrict the final analytic cohort to adults aged 18 years or older.

The proxy is a high-specificity research classification for probable finasteride-treated AGA, not a clinical diagnosis or a prevalence estimator for all AGA.

## Data provenance

All source data are publicly available from the [National Health and Nutrition Examination Survey](https://www.cdc.gov/nchs/nhanes/). Users should follow NCHS analytic guidance when modifying the survey design or pooled-cycle weights.

## Verified reference counts

The verified 2013–2018 reason-for-use inventory contains 151 male finasteride users: 8 with explicit hair-loss indications, 97 with prostate-related indications, and 46 with indeterminate indications. The internal criterion-evaluation set therefore contains 105 participants (8 hair-loss and 97 prostate-related indications). The final adult primary composite proxy contains 40 participants.
